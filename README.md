# トークテーマくじ引き

交流会やチームの集まりで使う、**トークテーマのくじ引き**です。
テーマを自分で登録して引けます。参加者側の登録もログインも要りません。

同じURLを開いた端末どうしで、テーマ・履歴・いま出ているテーマをそろえられます。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML1枚で完結。外部ライブラリ・ビルド不要） |
| `netlify/functions/kuji.mts` | 端末間の共有API（`/api/kuji`）。保存先は Netlify Blobs |
| `netlify.toml` | 公開設定（`index.html` の配信と関数の置き場所） |
| `package.json` / `package-lock.json` | 共有APIが使う依存だけ |

## 使い方

1. **テーマを編集** を開き、1行に1テーマで入力して **登録** を押します。
   - 改行を含むテキストをそのまま貼り付けると、1行ずつ別のテーマになります。
   - 行頭の「・」「-」「1.」などの記号と、重複は自動で落とします。
   - Excel の列をコピーした場合（タブ区切り）にも対応しています。
2. **スタート**（画面クリック、スペースキーでも可）で抽選します。
3. 決まったテーマは札に出たまま残ります。再読み込みしても続きから使えます。
4. 一度出たテーマは既定で除外されます。設定で切り替えられます。

## 端末間の共有

くじ引き画面の **「この端末の変更を共有する」** で切り替えます。

- **受け取りは常時**。誰かが共有した内容は、同じURLを開いている全員に届きます
  （5秒ごと、画面に戻ったときにも確認します）。
- **送り出すのはスイッチをオンにした端末だけ**です。オフの端末は受け取るだけで、
  その端末での編集や抽選は外に出ません。
- **今すぐ確認** を押すと、その場で取りに行きます。
- 抽選アニメーション中に届いた変更は、抽選が終わってから反映します。
- 共有APIが無い場所（`index.html` を直接開いた場合、関数の無いホスト）では
  スイッチ自体が出ません。アプリは単独で通常どおり動きます。

司会の端末だけをオンにしておくと、参加者の端末には同じテーマが映り、
誰かが引いたテーマは全員の「残り」から減ります。

共有される「くじ」はサイト全体で1つです。部屋分けはありません。

## そのほかの機能

- **この端末に保存する**（既定でオン）— テーマ・履歴・いま出ているテーマを
  そのブラウザに保存します。同じブラウザの別タブとも同期します。
- **効果音** — 回転中のカチカチ音と決定音（既定でオフ）。
- **全画面表示** — プロジェクタ投影用。
- 文字数に応じて札の文字サイズを自動調整し、最終行が1文字だけになる
  ぶら下がりも解消します。

## 公開手順（Netlify・GitHub 連携）

1. [Netlify](https://app.netlify.com/) にログイン。
2. **Add new site → Import an existing project → GitHub** でこのリポジトリを選択。
3. 設定は `netlify.toml` にあるので、基本はそのままで大丈夫です。
   - Build command: **空欄**
   - Publish directory: **`.`**
4. **Deploy site** で `https://<サイト名>.netlify.app` が発行されます。
   依存は Netlify 側で自動インストールされます。
5. サイト名は **Site configuration → Change site name** で変更できます。

以降は、連携したブランチに push するたびに自動で再デプロイされます。

## 初期テーマを変える

`index.html` の `SAMPLE_THEMES` を書き換えてください。
画面から登録したテーマはブラウザと共有APIに保存されるので、
初期値は「まだ何も保存されていないときに出るもの」です。

## ローカルで確認する

くじ引きだけ試すなら、`index.html` をブラウザで直接開くだけで動きます
（共有スイッチは出ません）。

共有まで含めて試すには Netlify CLI を使います。

```bash
npm install
npx netlify dev      # http://localhost:8888 で /api/kuji も動きます
```
